# 访谈提纲模板

| 访谈对象 | 核心问题 |
| --- | --- |
| 主要负责人 | 本年度重大安全风险是什么；是否定期带队检查重大事故隐患；重大问题如何挂牌督办 |
| 分管安全负责人 | 风险分级管控和隐患治理如何运行；重大隐患如何上报、整改、验收 |
| 业务部门负责人 | 如何落实管业务必须管安全；如何将安全职责分解到岗位 |
| 车间/项目负责人 | 本区域主要危险源、重点设备和危险作业是什么；班组如何开展日常检查 |
| 班组长 | 岗位风险、应急处置、交接班检查、违章制止如何落实 |
| 一线员工 | 是否接受岗位安全培训；是否知道紧急停机、报警、疏散和自救方法 |
| 承包商人员 | 是否完成入场教育和安全交底；作业票内容是否与现场一致；现场监护人是谁 |
