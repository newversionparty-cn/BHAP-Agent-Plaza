# Industry Modules

Use this reference to select inspection modules. Load only the relevant part.

## 通用国企安全管理

- 全员安全生产责任制
- 主要负责人和分管负责人履职
- 安全生产组织机构和人员配置
- 安全投入
- 安全生产标准化
- 双重预防机制
- 隐患排查治理
- 教育培训
- 事故事件报告
- 应急预案、演练、物资
- 承包商、外包、劳务派遣、灵活用工
- 考核问责、挂牌督办、整改销号

## 工贸

Use for 冶金、有色、建材、机械、轻工、纺织、烟草、商贸. Consider:

- 承包承租单位统一协调管理
- 特种作业人员持证
- 金属冶炼主要负责人和安全管理人员考核
- 粉尘涉爆
- 液氨制冷
- 有限空间中毒风险
- 设备防护、联锁、急停、报警
- 仓储、消防、电气、检维修

## 危化

Use only after checking current rules and local requirements. Consider:

- 两重点一重大
- 主要负责人和安全管理人员考核
- 特种作业持证
- 自动化控制、紧急停车、报警联锁
- 特殊作业：动火、受限空间、盲板抽堵、高处、吊装、临时用电、动土、断路
- 储罐区、装卸、变更管理、试生产、承包商

## 建筑施工

- 安全生产许可证和项目安全管理体系
- 危大工程方案、论证、交底、验收
- 高处作业、脚手架、模板支撑、深基坑、起重机械
- 临时用电、消防、生活区
- 分包单位和劳务人员管理

## 电力/能源

- 两票三制
- 设备检修、倒闸操作、带电作业
- 高处、有限空间、动火、吊装、临电
- 外委队伍和作业许可
- 应急保供、消防、防汛、防台

## 燃气

- 场站、管网、调压设施、阀井
- 泄漏检测、报警联锁、通风防爆
- 第三方施工破坏防控
- 入户安检、应急抢修
- 消防、电气、防雷、防静电

## 仓储/物流

- 货物分类分区、堆码、防火间距
- 叉车、装卸、充电区
- 危险化学品或易燃品存放
- 消防通道、安全出口、疏散标识
- 外来车辆和承包商作业

## Common Hazardous Operations

For any industry, consider special modules for:

- 动火作业
- 有限空间作业
- 高处作业
- 吊装作业
- 临时用电
- 检维修
- 盲板抽堵
- 动土/断路
- 交叉作业
