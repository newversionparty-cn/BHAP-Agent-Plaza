# BHAP Context

Use when the user mentions BHAP, 北汽海纳川, 海纳川, or asks for this skill in a Beijing Hainachuan / automotive-parts manufacturing context.

## Default Framing

Treat BHAP-EHS as a manufacturing-group EHS skill:

- group headquarters / subsidiary / factory / park / workshop / team layers
- contractor, outsourced service, logistics, equipment maintenance, construction and renovation work
- EHS/HSE governance, safety production, emergency management, fire, occupational health, environmental and energy-management adjacency when requested

Do not assume a specific plant, legal entity, city, process, or company制度 unless the user provides it. Mark missing items as `待补充` or `需用户提供制度文件`.

## Preferred Language

Use formal internal-management language:

- 集团督导
- 子企业履责
- 穿透式管理
- 现场可核验
- 隐患整改闭环
- 重大事故隐患判定关注项
- 承包商统一协调管理
- 挂牌督办
- 复查销号

Avoid public marketing language unless the user explicitly asks for an external article.

## Typical BHAP-EHS Modules

For a manufacturing or automotive-parts setting, consider:

- 冲压、焊接、涂装、注塑、装配、机加、模具维修, if applicable and user confirms
- 设备防护、联锁、急停、点检、检维修
- 电气、消防、特种设备、叉车、仓储物流
- 动火、有限空间、高处、吊装、临时用电、交叉作业
- 承包商、外委检维修、施工改造
- 危化品或易燃品储存使用, if present
- 粉尘、噪声、职业健康, if present
- 应急预案、演练、事故事件报告

When uncertain, ask for or mark the exact process and site risk profile.
