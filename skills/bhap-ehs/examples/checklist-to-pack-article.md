# 示例：从检查清单到检查包的文章结构

Use when the user asks for an internal article, preface, briefing, or management explanation.

Recommended structure:

1. 单张清单只能回答“查什么”，检查包要回答“依据、方法、证据、判定、整改、销号”。
2. 依据矩阵解决检查合法性和可追溯问题。
3. 问、查、看、测、演解决检查项空泛问题。
4. 国企责任链条解决总部、子企业、基层、承包商之间的穿透式管理问题。
5. 重大事故隐患单列，支撑动态清零和闭环管理。
6. 检查包是可执行、可取证、可追责、可闭环的管理工具。
