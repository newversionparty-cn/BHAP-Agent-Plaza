# 海纳川 PPT 写作口径

## Tone

- Use formal internal-report language suitable for management review.
- Prefer concrete management verbs: `明确`, `沉淀`, `形成`, `验证`, `适配`, `贯通`, `复制推广`, `验收`.
- Keep each slide title as a conclusion, not a topic label.
- Avoid internet-style expressions, exaggerated slogans, or vague “赋能/协同” stacking.

## Required Boundary Wording

For member-enterprise energy/EMS/double-carbon work:

- Headquarters provides standards, API entry, template rules, review support, controlled computing quota guidance, and Agent setup support.
- Headquarters participates to prevent procurement and architecture from going off track; it does not take over factory operations.
- Member enterprise owns construction, operation, data quality, monthly confirmation, and supplier management.
- Supplier must keep protocol, data dictionary, export, and API integration capability open and verifiable.
- Headquarters receives standard monthly data; high-frequency raw meter/MQTT data stays on the factory side.

## Preferred Terms

- Use `总部侧`, `成员企业`, `成员企业复制路径`, `标准接入包`, `供应商准入`, `接口适配`, `字段映射`, `月度标准数据`.
- For existing systems, write `已有能源管理系统，优先做接口适配、字段映射和月报贯通`.
- For new systems, write `从采购阶段前置数据开放、接口适配和模块化交付要求`.

## Banned Or Risky Terms

- Do not use `集团` or `集团级` unless the user explicitly confirms that wording is correct.
- Avoid `集团级复制路径`; use `成员企业复制路径` or `成员企业推广路径`.
- Avoid promising unlimited computing power or unrestricted usage quota. Use `受控资源`, `额度管理`, `调用审计`, `成本可控`.
- Do not imply headquarters operates the factory system. Use `协助`, `支持`, `把关`, `标准制定`, `接口接收`.

## Slide Copy Pattern

Use this pattern for most slides:

1. Title: conclusion sentence.
2. Message band: one sentence explaining why the slide matters.
3. Proof object: matrix, architecture, process, timeline, or comparison.
4. Bottom conclusion bar: one crisp management judgment.
