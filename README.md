# BHAP-Agent-Plaza

海纳川智能体技能库

BHAP-Agent-Plaza is a public, agent-readable catalog of reusable skills selected from a local multi-agent workstation. It keeps only public-safe, reusable, execution-oriented skills and excludes private agents, identity profiles, auth/session files, caches, backups, and temporary downloads.

## Agent Manifest

- JSON manifest: [manifest/skills.json](manifest/skills.json)
- Skill directory: [skills/](skills/)
- ZIP downloads: [dist/](dist/)

## Selection Rules

- Include public-safe skills with clear execution value, reusable workflows, and stable entrypoints.
- Exclude private agents, identity profiles, auth/session material, local caches, backups, generated dependency caches, and temporary downloads.
- Treat plugin caches as managed dependencies, not as canonical source material.
- Use `~/.agents/skills` as the local canonical skill root when the same workstation shares a skill across Codex, Claude, and OpenClaw.

## Repository Layout

```text
skills/<slug>/SKILL.md
manifest/skills.json
dist/<slug>.zip
```
